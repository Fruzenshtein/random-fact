# Випадковий факт

Простий застосунок, який при відкритті показує випадковий факт про інформатику
або інформаційну безпеку. Працює повністю на стороні клієнта (HTML, CSS, JS),
тому його можна розмістити на GitHub Pages без жодного бекенду.

## Як користуватись

- Відкрий сторінку — зʼявиться випадковий факт на весь екран.
- Онови сторінку, щоб побачити наступний факт. Той самий факт двічі поспіль
  не показується.
- Кнопка «План декади» під фактом відкриває розклад декади інформатики.
  Під час декади сторінка сама прокручується до сьогоднішнього дня, а панель
  дат угорі дозволяє швидко перейти до будь-якого дня. Кнопка «Назад»
  повертає на головну.

## Структура

| Файл         | Призначення                                        |
| ------------ | -------------------------------------------------- |
| `index.html` | Розмітка сторінки                                  |
| `styles.css` | Стилі: синьо-жовтий розмитий фон, типографіка      |
| `app.js`     | Вибір випадкового факту та підбір розміру шрифту   |
| `facts.js`   | Список фактів (до 12 слів кожен)                   |

Щоб додати або змінити факт, відредагуй масив у `facts.js`. Щоб змінити
розклад, відредагуй `plan-data.js`: кожен день має `date` у форматі
`РРРР-ММ-ДД`, назву дня тижня та список заходів із полями `title`, `note`,
`classes` і `owner`. Для перевірки вигляду іншого дня можна відкрити
`plan.html?today=2026-11-18`.

## Локальний запуск

Відкрий `index.html` у браузері або запусти будь-який статичний сервер,
наприклад:

```bash
python3 -m http.server 8000
```

і перейди на <http://localhost:8000>.

## Публікація на GitHub Pages

1. Запуш код у гілку `main` на GitHub.
2. У репозиторії відкрий **Settings → Pages**.
3. У розділі **Build and deployment** вибери **Deploy from a branch**,
   гілку `main` і теку `/ (root)`, натисни **Save**.
4. Через хвилину сайт буде доступний за адресою
   `https://<користувач>.github.io/<репозиторій>/`.
