# Filter Image

Гра «вгадай зображення»: фото показується сильно пікселізованим, а ведучий
крок за кроком покращує якість, доки клас не вгадає, що на картинці.

## Керування

| Дія                     | Миша                         | Клавіатура        |
| ----------------------- | ---------------------------- | ----------------- |
| Покращити якість на крок | кнопка **Enhance quality**  | `Space` або `Enter` |
| Показати оригінал       | кнопка **Reveal**            | `R`               |
| Попереднє / наступне фото | стрілки ліворуч і праворуч | `←` / `→`         |

Пʼять натискань Enhance ведуть від найгрубішої мозаїки до оригіналу:
32 → 48 → 72 → 108 → 160 блоків по ширині → оригінал. Крапки під фото
показують, скільки кроків уже зроблено. При перемиканні фото маска
скидається до найгрубішої.

## Як додати свої фото

1. Поклади файли у теку `images/`. Найкраще квадратні зображення
   (JPG, PNG, WebP або SVG), орієнтовно 1000×1000 пікселів.
2. Перелічи їх у файлі `images.js` у тому порядку, в якому вони мають
   показуватись:

```js
window.IMAGES = [
  "images/cat.jpg",
  "images/kyiv.jpg",
  "images/keyboard.png"
];
```

3. Тестові файли `sample-1.svg`, `sample-2.svg`, `sample-3.svg` можна
   видалити, прибравши їх і зі списку.

Сусідні фото підвантажуються наперед, тому перемикання стрілками миттєве.
